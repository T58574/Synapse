# Идеи по улучшению и развитию проекта (Backlog)

В этом файле фиксируются идеи по развитию аудиоплеера, предложения по интерфейсу, интеграциям и юзабилити, а также решения по ним.

| Идея / Точка роста | Описание | Статус | Примечание |
| :--- | :--- | :--- | :--- |
| **Интеграция SoundCloud в интерфейс** | Добавление полноценной вкладки SoundCloud на фронтенд для поиска и скачивания треков напрямую через UI. | **Отказ (Rejected)** | Отказано пользователем. Решено полностью вырезать все упоминания и бэкенд-реализацию SoundCloud из проекта. |
| **Поддержка Drag-and-Drop** | Возможность перетаскивать аудиофайлы напрямую в окно плеера для воспроизведения или импорта в медиатеку. | **Отказ (Rejected)** | Отказано пользователем. Неинтересно для текущей версии продукта. |
| **Горячие клавиши (Hotkeys)** | Управление воспроизведением (Play/Pause, Seek, громкость) с помощью клавиш клавиатуры. | **Отказ (Rejected)** | Отказано пользователем. Не требуется. |
